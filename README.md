Doxa is a high-performance, conversion-optimized landing page designed for a next-generation decentralized zero-knowledge consensus layer and autonomous AI agent cloud.

## Quickstart

```bash
# Install dependencies
npm install

# Start development server
npm run dev
```

Visit [http://localhost:3000](http://localhost:3000) to view the live application.

## Core Features & Architecture
- **Component-Driven Architecture (CDA)**: Modular atomic system (`atoms`, `molecules`, `organisms`).
- **Core Web Vitals Optimized**: < 1.0s target LCP, 0 CLS, and responsive fluid layouts (320px to 4K).
- **Interactive Holographic Telemetry**: Live mock daemon console, TPS counter, and real-time block latency simulator.
- **Interactive Protocol Flow**: 4-phase architecture selector with synchronous code generation.
- **WCAG 2.1 AA Compliant**: Focus rings, ARIA landmarks, accessible contrast ratios.
- **Full Handover Guide**: Read [docs/HANDOVER_GUIDE.md](docs/HANDOVER_GUIDE.md) for full prop tables, design tokens, and deployment guides.
